|-----|---|

## 计分公式

```
最终分数 = 总Chips × 总Mult

计分流程：
1. 牌型基础值
2. 逐张卡牌计分（左→右，含强化/版本效果）
3. 手牌持有效果（Steel ×1.5）
4. 小丑独立效果（先+chips/+mult，后×mult）
```

## 联机流程

### 房主
```
MainMenu → 创建房间 → CreateRoom场景
→ 显示IP → 等待玩家 → 开始游戏
```

### 客户端
```
MainMenu → 加入房间 → JoinRoom场景
→ 输入IP → 连接 → CreateRoom场景 → 等待开始
```

## 核心规则

| 规则 | 说明 |
|-----|------|
| 出牌 | 一局只能出一次，出后观战 |
| 弃牌 | 每次消耗1次弃牌次数，立即补牌 |
| 借钱 | 仅主菜单可借，游戏中禁止 |
| 赢钱 | 优先还债，剩余计入账户 |
| 小丑顺序 | 从左到右触发，先+后× |
